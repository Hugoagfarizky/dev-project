# SimuForge

**Build. Program. Simulate.**

SimuForge is a browser-based programmable simulation sandbox. Users build virtual environments, create objects and systems, program their behavior with visual scripting or Python, and run interactive simulations.

## Status

**Concept / Specification.** SimuForge is in the concept definition stage. There is no implementation and no proof of concept. All architecture and technology choices are proposed and unvalidated.

## Planned MVP Increments

| Increment | Scope |
| --- | --- |
| MVP-0 | Studio and world foundation |
| MVP-1 | Components and basic physics |
| MVP-2 | Visual scripting |
| MVP-3 | Integrated demonstration and monitoring |

Python support is planned as a separate increment after the initial visual-scripting workflow. Details and acceptance criteria are in the [product specification](docs/PRODUCT_SPECIFICATION.md).
