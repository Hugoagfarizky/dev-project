2. Runtime states

State is communicated by a pill, the runtime bar, and the transport — never by color alone.

Editing Preparing Running Paused Stopped

Editing: authored state is writable. Preparing: lock begins. Running: live values. Paused: runtime frozen. Stopped: transient handoff back to Editing.

5. Border, radius, elevation

Radius communicates containment, not decoration. Elevation is reserved for overlays, popovers, and the empty-world card.

Elevation 1 is a 1 px separation for raised rows. Elevation 2 is menus and popovers. Elevation 3 is modal/overlay. No elevation on docked panels.

7. Button hierarchy

One primary action per surface. Run is the primary action in Editing; Pause is primary while Running; Stop is the explicit exit.

Variants

Loading buttons keep their width and label; the spinner replaces the leading icon. Destructive actions are never the default focus.

Icon buttons and states

Focus0.000 Read-only1.250

Focus ring: 2 px selection-colored halo. Hover is surface-only; pressed adds the inset selection bar. Disabled is 38% opacity and non-interactive.

12. Motion and accessibility

Motion

instant0 msSelection, typing
fast120 msHover, focus
base180 msPanel expand
slow240 msDrawer, overlay

Respect prefers-reduced-motion: replace panel and drawer transitions with instant state changes; keep the runtime pulse optional.

Accessibility rules

Visible focus on every interactive element.
State conveyed by text, shape, and color.
Minimum 24 px hit target; 28 px preferred.
No color-only selection or error cue.
Runtime changes announced, not focus-stealing.

Contrast targets: body text 4.5:1, large text 3:1, non-text UI 3:1. Disabled text is exempt but must remain legible.
