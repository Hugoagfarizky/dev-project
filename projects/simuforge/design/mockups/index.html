How to review. Open any card in Chrome at 1440 × 900. The pages are static HTML and CSS with no JavaScript, no build step, and no external assets. Compare the workspace pages with Workspace Layout, and use Main User Flows to trace each interaction. The mockups are review evidence, not a scaffold: no application code, dependencies, or component library are introduced here.
What is intentionally not shown. Floating panels, drag-to-dock, multi-select, hybrid 2D/3D, light theme, and live node tracing are deferred. Capabilities that belong to a later phase are either absent or labelled Planned; they are never presented as working.
