Test checklist

  1. T-01 World Translate: Drag X, Y, Z handles; verify movement follows world axes.
  2. T-02 World Rotate: Rotate ~45° then ~90° around world Y; record quaternion/Euler.
  3. T-03 Local Scale (unrotated): Individual axes and non-uniform scale; verify local-axis behavior.
  4. T-04 Local Scale (rotated): Rotate ~45° (and ~90°) around Y; test local scaling.
  5. T-05 Mode Switching: Translate → Rotate → Scale → Translate without dragging; verify no transform change.
  6. T-06 Transform Integrity: Finite components, quat length ~1 (tol 1e-5), no negative/zero scale, no shear.

Log

How to use: Open this file in Google Chrome. Use the mouse to drag gizmo handles. Select a mode with the buttons (or use the gizmo's own handles). Reset restores the initial cube. "Capture State" records the current transform without an observation. "Record Observation" adds your note plus before/after transforms. "Export JSON" downloads the collected evidence. Pointer start/end coordinates are captured when available; otherwise marked unavailable. Visual verification is performed by you; this harness does not declare PASS.
