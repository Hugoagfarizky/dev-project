# SimuForge — POC-01 Evidence Index

Status: SP-01 executed; SP-02 to SP-08 not started.

## How to read
- `environment.md` — captured OS, hardware, browser, and dependency versions.
- `results/spike.md` — one section per spike step (SP-01 to SP-08) with action, observation, pass/fail, and evidence links.
- `results/acceptance.md` — acceptance criteria results (to be created when relevant tests run).
- `screenshots/` — full-window screenshots named by test ID, date, and browser.
- `issues.md` — defects, severity, workaround, status.
- `performance/` — raw metrics and notes (to be created when performance tests run).

## Current scope
- Browser: Google Chrome only (Chrome-only scope approved for POC-01).
- Cross-browser compatibility is outside POC-01 scope.
- No POC acceptance criterion is marked PASS without an evidence artifact.
